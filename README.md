
# Wine Quality: Clustering and Fitting

## Project overview
This project analyses red and white Portuguese Vinho Verde
wine samples using Python.

## Objectives
- Clean and prepare the dataset
- Calculate mean, variance, skewness and kurtosis
- Create relational, categorical and statistical plots
- Apply K-means clustering
- Fit a regression model to predict wine quality
- Evaluate model performance

## Dataset
Source: UCI Machine Learning Repository
https://archive.ics.uci.edu/dataset/186/wine+quality

The dataset contains physicochemical measurements and
wine quality scores. Please consult the original source
for dataset details and licensing.

## Libraries
- pandas
- NumPy
- Matplotlib
- Seaborn
- SciPy
- scikit-learn

## How to run
Install the required libraries, obtain the red and white
CSV files from UCI, and run the Python analysis script.
